## Опис репозиторію

Цей репозиторій створено для виконання лабораторних та практичних робіт з дисципліни **«Web Technologies»**.

У репозиторії будуть представлені навчальні проєкти, вихідний код та результати виконання практичних завдань, пов'язаних із вебтехнологіями та програмуванням.

## Мови програмування

Мої улюблені та основні мови програмування:

* **C#** — розробка програм на платформі .NET,WinForms, робота з API та базами даних.
* **C++** — об'єктно-орієнтоване програмування, алгоритми та структури даних.
* **PHP** — розробка вебзастосунків.
* **Java** — розробка серверних застосунків.
* **Lua** — створення ігор та робота з ігровими рушіями.
